# Programación Orientada a Objetos
## Laboratorio #3

Este laboratorio trata de un sistema de envios con uso de herencia
La entrega puede ser departamental o urbana 
los pedidos pueden ser de 4 tipos:
1. Documentos/Sobre
2. Paquetes
3. Paquetes Frágiles
4. Paquetes Fríos

Dependiendo del paquete se cobra diferente 
Para compilar el codigo usa:
´´´
    javac -d bin src/*.java
´´´
Para ejecutar usa el código:
´´´
    java -cp bin Main
´´´
